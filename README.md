# A4PRINT — Print xizmati sayti

A4PRINT — top-10 buyumga chop etish xizmati uchun adaptiv sayt.

## GitHub Pages orqali jonli qilish

1. GitHub'da yangi repozitoriy oching (masalan: `bosma-site`)
2. `index.html` va `README.md` fayllarini yuklang (**Add file → Upload files**)
3. **Settings → Pages → Branch: main → Save** bosing
4. 1-2 daqiqadan so'ng sayt shu manzilda ochiladi:
   `https://SIZNING-LOGIN.github.io/bosma-site/`
